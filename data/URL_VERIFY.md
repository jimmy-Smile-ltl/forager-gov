# 全量 URL 身份核查（p240 系列）

> 2026-11-18 全站一轮。目的：**发布的每个 URL 都必须属于它挂的那个机构**，
> 不是只看连通性。WAF/IP 封锁按项目口径**默认正确**（走隧道代理复验），只清
> 有身份证据的错配；死链只报告不动树（连续两轮 dead 才列名）。

## 口径

- 范围：树节点 URL + registry-only 记录，共 **28,769 条记录 / 22,866 个唯一 URL**，逐条实抓。
- 判身份三维：**地区**（路径沿革推定本级及上级，标题必须含最深层行政区）、
  **机构类型**（人大/政协/法院/检察/监委 × 政府——互斥角色才算冲突）、
  **文章页**（`/art/`、`/content_`、`/doc/`、6 位日期目录等一律不是机构入口）。
- 分档：`ok` / `ok_neutral`（中性标题，如「清风扬帆网」）/ `waf`（含 4xx 反爬，
  默认正确）/ `suspect`（只报告）/ `dead`（只报告）/ `mismatch`（唯一可清除档）。
- 清除按**节点**：同一个 URL 在别的节点上正确时不清树；registry 只在该 URL
  树里已无任何存活节点时清除。

## 结果

| 档 | 记录 | 唯一 URL |
|---|---:|---:|
| ok | 20,617 | 17,447 |
| ok_neutral | 2,284 | 1,498 |
| waf（默认正确） | 4,746 | 3,101 |
| suspect（只报告） | 724 | 649 |
| dead（只报告） | 52 | 49 |
| mismatch（已清除） | 346 | 122 |

落库：

- 清除错配 **311 个节点 / 149 个唯一 URL**；registry 同步清除 186 条
  （另 4 条「树已清空但 registry 还留着」的历史条目一并清掉）。
- 结构清理：删除误挂在市/区县「市级政府部门」组下的**省级部门节点 259 个**
  （江门 36、天津河北区 30、池州 28、大兴安岭 27、凉山 24、玉树 24、海西 22、白城 19…）。
- 文章/详情页处置（p240b）：**436 个节点根化到本站根页**、**10 条根页也不合格
  的清空列名**（多为县级机构只有门户栏目页的情况）。

错配集中在：国家部委/国家级平台 URL 挂到地方节点（ccdi、stats、gjxfj、nra、
ncha、saac、nea、ndrc、mem、ggj、spb、cea、ncac、cnipa、cnsa、mohurd、forestry）、
上级纪委/人大/政协站点顶替县级机构（重庆 jjc.cq、柳州 jcw、恩施 eslzw、抚州 fzlz、
菏泽 hzsjwjcj、德州市监、昆明市监、保山市监、宁夏/贵州/四川省纪委监委）、
跨地同名区县错配（徐州/开封鼓楼→福州鼓楼，鞍山/四平铁西→沈阳铁西，长沙雨花→
南京雨花台，海口龙华→深圳龙华，张家界永定→龙岩永定，上海宝山→双鸭山宝山，
重庆江北→宁波江北，陇县→陇西，枣庄市中→内江市中，杨陵→夷陵）、
以及重定向到无关站点的死域（xjwqfy.chinacourt.gov.cn 现为「中国气象科普网」）。

## 本轮修掉的误判（都会误杀正确 URL，逐条已回归验证）

1. **复合地名**：条树叶子「徐州鼓楼区法院」不能再拆出不存在的地名「徐州鼓楼」，
   也不能把「沧源佤族自治县」剥成「佤族自治县」——按「基底是否已知」分辨正名与复合名。
2. **本地名的尾巴**：标题「…连南县/镇宁县/紫云县/市南区…」里的「南县/宁县/云县/南区」
   是别处真县名，但与期望地名在标题里紧挨着 → 同一地方，不算外地。
3. **下辖县区兜底**：市级节点标题写本市下辖县区（清远中院 × 连南瑶族自治县）不算错配；
   路径缺市一级时，标题带父市（西湖区法院 → 杭州市西湖区人民法院）也不算。
4. **马鞍山市 ≠ 鞍山市**：长地名的尾巴不是另一个地区。
5. **以「市」开头的真区名**：市南区、市北区、市中区（青岛/枣庄/内江/乐山/济南）。
6. **简称与合署**：喀左＝喀喇沁左翼蒙古族自治县；重庆/四川自贸区法院＝自由贸易试验区法院；
   西部科学城重庆高新区、民航西南地区管理局、乌鲁木齐经开区（头屯河区）等记入 ALLOW_OK。

# 跨地区串站裁决与回填（p243 / p241 / p241b / p244，2026-11-18）

p240 按节点自己的地区逐条核查，**标题只写县名的站对多个同名区县都能通过**——
`www.szq.ls-jcy.gov.cn`（乐山市市中区检察院）同时挂在济南/枣庄/内江/乐山四个
「市中区」上；`www.dtsrd.gov.cn`（大同市人大常委会）挂在大庆市大同区人大上。
这一类只有把同一 URL 的多个挂载点放在一起比才能判出归属。

## p243 裁决规则

1. 五系统节点按 URL 分组，组内 ≥2 个不同「地区身份」即冲突组；
2. 身份 = 省 + 地名基底 + 机构类型（+城市，同省同基底跨市才拆）；
3. 用页面 title/snippet 给每个身份打分（地区链全名 ×3/×2/×1，snippet 减半），
   先按标题判、标题并列再用 snippet；
4. 唯一最高分身份保留，标题分/snippet 分全 0 的身份清空留名；
   **同一机构的结构变体不清**——条树简称/旧名（锦州检察院、奉化市、黔西县、
   隆林县、广州检察院）与「州/地区 ↔ 同名市」（恩施州院 vs 恩施市院、
   阿勒泰地区 vs 阿勒泰市）靠地名形态集合区分。

结果：冲突组 135 → 唯一归属 20 组，**清除 24 个节点 / 9 条 registry**。
典型：市中区检察院挂 4 地、大同区人大 ← 大同市人大、海城区检察院 ← 海城市检察院、
中山区检察院 ← 中山市检察院、甘南县检察院 ← 甘南州检察院、金川县监委 ← 金川区纪委、
阿勒泰地区 ← 阿勒泰市检察院。

## p241 回填（只补「清除后留名」的节点）

给 verify() 加了**URL 归属索引**：全树已有 URL（精确 + 站点根址的主机级，
主机名去 www 归一）属于别的地区/系统时，候选一律驳回——否则 p241 会把刚
被 p243 清掉的错配 URL 原样填回去（实测大同区/河口区/金川县/宁县/西市区/龙港区
六例）。同时补了复合地名基底归一（「阳泉城区法院」↔「城区/县人民法院」）。

本轮 p243 清除节点的回填结果：**填充 15 个**（中山区/甘南县/兴安区/海城区/
大理市/临夏市/昌吉市/塔城市/阿勒泰地区 检察院 + 龙港区/恩施市 监委 +
中山区/甘南县/海城区 检察院块节点 + 阿勒泰地区 检察院块节点经条块同步），
**9 个渠道穷尽留名**（西市区人大、龙港区政协、昌邑区政协、东港区政协、
大同区人大、河口区检察院、金川县监委、宁县人大、楚雄市检察院）。

## p241b 独立复核

失败项全部清除（12388 文章页、门户 xxgk 栏目、群团站、人大建议栏目、

  不算跨地区错配（TITLE_SELF_PARENT）。
