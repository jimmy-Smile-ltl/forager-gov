# 全量 URL 身份核查（p240 系列）

> 2026-11-18 全站一轮。目的：**发布的每个 URL 都必须属于它挂的那个机构**，
> 不是只看连通性。WAF/IP 封锁按项目口径**默认正确**（走隧道代理复验），只清
> 有身份证据的错配；死链只报告不动树（连续两轮 dead 才列名）。

## 口径

- 范围：树节点 URL + registry-only 记录，共 **28,769 条记录 / 22,866 个唯一 URL**，逐条实抓。
- 判身份三维：**地区**（路径沿革推定本级及上级，标题必须含最深层行政区）、
  **机构类型**（人大/政协/法院/检察/监委 × 政府——互斥角色才算冲突）、
  **文章页**（`/art/`、`/content_`、`/doc/`、6 位日期目录等一律不是机构入口）。
- 分档：`ok` / `ok_neutral`（中性标题，如「清风扬帆网」）/ `waf`（含 4xx 反爬，
  默认正确）/ `suspect`（只报告）/ `dead`（只报告）/ `mismatch`（唯一可清除档）。
- 清除按**节点**：同一个 URL 在别的节点上正确时不清树；registry 只在该 URL
  树里已无任何存活节点时清除。

落库：

- 清除错配 **311 个节点 / 149 个唯一 URL**；registry 同步清除 186 条

- 结构清理：删除误挂在市/区县「市级政府部门」组下的**省级部门节点 259 个**
  （江门 36、天津河北区 30、池州 28、大兴安岭 27、凉山 24、玉树 24、海西 22、白城 19…）。
- 文章/详情页处置（p240b）：**436 个节点根化到本站根页**、**10 条根页也不合格
  的清空列名**（多为县级机构只有门户栏目页的情况）。

## 本轮修掉的误判（都会误杀正确 URL，逐条已回归验证）

1. **复合地名**：条树叶子「徐州鼓楼区法院」不能再拆出不存在的地名「徐州鼓楼」，
   也不能把「沧源佤族自治县」剥成「佤族自治县」——按「基底是否已知」分辨正名与复合名。
2. **本地名的尾巴**：标题「…连南县/镇宁县/紫云县/市南区…」里的「南县/宁县/云县/南区」
   是别处真县名，但与期望地名在标题里紧挨着 → 同一地方，不算外地。
3. **下辖县区兜底**：市级节点标题写本市下辖县区（清远中院 × 连南瑶族自治县）不算错配；
   路径缺市一级时，标题带父市（西湖区法院 → 杭州市西湖区人民法院）也不算。
4. **马鞍山市 ≠ 鞍山市**：长地名的尾巴不是另一个地区。
5. **以「市」开头的真区名**：市南区、市北区、市中区（青岛/枣庄/内江/乐山/济南）。
6. **简称与合署**：喀左＝喀喇沁左翼蒙古族自治县；重庆/四川自贸区法院＝自由贸易试验区法院；
   西部科学城重庆高新区、民航西南地区管理局、乌鲁木齐经开区（头屯河区）等记入 ALLOW_OK。

## 复跑

```bash
cd data
uv run python p240_full_url_verify.py --report          # 只出报告（读 p240_results.jsonl 断点续跑）
uv run python p240_full_url_verify.py --prune --apply   # 结构清理 + 按节点清除 mismatch
uv run python p240b_article_fix.py [--apply]            # 文章页根化/清空
```

`p240_results.jsonl`（抓取断点）与 `url_verify_report.json`（全量报告，16MB）不入库，
需要时按上面命令重跑即可复现。
